# localU icon set

Brand icon set for **localU** — the LocalSend fork focused on syncing mobile
devices with portable storage (U 盘 / mobile SSD).

## Design

LocalSend's visual DNA — a ripple ring of 8 tapered arc petals (wireless
transfer) — kept intact; the solid center dot is replaced by a bold rounded
**U** (USB drive + the product's initial), reading as a "receiving vessel"
for files synced into storage.

- Primary colorway: **USB blue `#1B82D6` — signed off 2026-10-03** (distinct
  from LocalSend teal on purpose — two related products must not be confused
  at a glance)
- Alt colorways (archive only, not shipped): `alt/logo-512-teal.png`
  (LocalSend family teal `#17868C`), `alt/logo-512-black.png`
- Geometry lives in `generate.py` (pure-stdlib renderer, no dependencies)

## Files (mirrors `app/assets/img/`)

| File                 | Used for                                   |
|----------------------|--------------------------------------------|
| `logo.svg`           | Vector source (launchers derive from the same geometry via `make_launchers.py`) |
| `logo-512.png`       | In-app "about" logo (`LocalSendLogo` widget tints it via `BlendMode.srcATop`) |
| `logo-256.png`       | Stores / packaging                         |
| `logo-128.png`       | Small in-app / docs                        |
| `logo-32.png`        | Small UI references                        |
| `logo-32-black.png`  | macOS / Windows light tray icon            |
| `logo-32-white.png`  | Dark tray icon                             |
| `logo-512-white.png` | Dark surfaces                              |
| `logo.ico`           | Windows app icon (16–256, PNG-embedded)    |

## Regenerate / restyle

```bash
python3 generate.py                    # primary USB-blue set
python3 generate.py --color teal       # LocalSend-teal colorway
python3 generate.py --color '#RRGGBB'  # custom
```

Single source of truth: `PETALS / RING_R / PETAL_*` (ring) and
`U_A / U_S / U_TOP_Y / U_BOWL_Y` (U glyph) at the top of `generate.py`.
PNG, SVG and ICO are all derived from the same capsule-chain geometry and
verified pixel-identical (see `chain_outline` / `rasterize_master`).

## Platform launchers (`launchers/`)

Generated by `make_launchers.py` from the same geometry, mirroring the
layout of LocalSend's own launcher assets — fractions measured from the
repo PNGs, not guessed:

| Target                                    | Treatment (glyph-box fraction of canvas)            |
|-------------------------------------------|-----------------------------------------------------|
| Android legacy `ic_launcher` / `_round`   | white circle Ø 0.917 + glyph 0.703                  |
| Android adaptive `…_foreground`/`_monochrome` | glyph 0.512 on the 108dp grid (white when monochrome) |
| Android `…_quicktile_foreground`          | white glyph 0.611                                   |
| iOS `AppIcon.appiconset`                  | opaque white full-bleed + glyph 0.762               |
| macOS `AppIcon.appiconset` + `.icns`      | transparent + glyph 0.805                           |
| Windows `runner/resources/app_icon.ico`   | transparent glyph 16–256                            |
| web `icons/Icon-*`                        | white full-bleed 0.62, maskable 0.55                |

Treatment decisions taken from decoding LocalSend's actual files: the iOS
1024 icon is opaque RGB (white full-bleed); the adaptive monochrome layer
ships as white RGB + alpha (Android reads alpha only); LocalSend's web
icons are stock Flutter placeholders, so localU's are designed fresh.

Output tree mirrors the repo paths, so it drops in with plain copies:

```bash
cp -R launchers/android/app/src/main/res/* app/android/app/src/main/res/
cp -R launchers/ios/Runner/Assets.xcassets/AppIcon.appiconset/*  <same repo path>
cp -R launchers/macos/Runner/Assets.xcassets/AppIcon.appiconset/* <same repo path>
cp launchers/windows/runner/resources/app_icon.ico <same repo path>
cp launchers/web/icons/* app/web/icons/
```

Both `Contents.json` catalogs are copied verbatim from the repo (same
filenames). `localu.icns` is built with `iconutil` (macOS host required);
`qa_sheet.png` is a contact sheet of the generated set.

```bash
python3 make_launchers.py              # signed-off USB blue
python3 make_launchers.py --color teal # restyle the whole launcher set
```

## Not covered

Linux `.png` theme sizes (`app/linux/packaging/{deb,rpm}`) — plain sized
PNGs; derive from `logo.svg`/`logo-*.png` when packaging for Linux.
